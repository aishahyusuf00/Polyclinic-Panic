# 🦷 Dental School Simulator: Polyclinic Panic!

A 3D time-management clinical simulator built with Three.js, HTML5, Web Audio API, and JavaScript.

## 🚀 How to Deploy

### Option 1: Deploy to Netlify
1. Log into your [Netlify](https://www.netlify.com/) account.
2. Drag and drop the folder containing `index.html`, `styles.css`, `sound.js`, `game.js`, and `README.md` onto the Netlify drag-and-drop landing area.
3. Your site will immediately be published with a live web link!

### Option 2: Deploy to GitHub Pages
1. Create a repository on GitHub (e.g. `dental-school-simulator`).
2. Push all 5 files to the `main` branch.
3. Open **Settings** -> **Pages**.
4. Set Source to `Deploy from a branch`, select `main`, and click **Save**.
